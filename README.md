# Task-3
contact management system that stores data in memory

This program:

Uses a dictionary to store contacts in memory
Provides options to add, view, edit, and delete contacts
Prompts for name, phone number, and email when adding or editing
Displays all contacts or handles cases where no contacts exist
Includes a loop for continuous operation until the user chooses to exit
Handles invalid inputs with appropriate messages
For persistent storage in a file, you would need to add file I/O operations (e.g., using json to save and load the contacts dictionary),but this version keeps it simple with in-memory storage.
